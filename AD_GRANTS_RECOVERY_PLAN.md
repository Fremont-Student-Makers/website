# Google Ad Grants Recovery Plan

## Goal

Fix the issues Google called out by making the site faster to load, easier to navigate, and stronger for indexing and conversions.

## What This Plan Addresses

- Clear navigation and page hierarchy
- Less repeated or filler content
- More substantial, up-to-date page copy
- Better calls-to-action on each page
- Cleaner metadata for search indexing
- A reusable blank template for new portfolio pages

## Priority Order

### 1. Navigation and page structure

- Keep one primary navigation path from the homepage to the major sections.
- Make the homepage point to only the most important next steps.
- Make every subpage include a clear back link and one obvious CTA.

### 2. Content quality

- Replace duplicated copy with page-specific text.
- Add concrete details, dates, outcomes, and project evidence.
- Remove placeholder text from any live page.

### 3. Speed and technical cleanup

- Reduce unnecessary visual weight on the homepage.
- Keep images compressed and correctly sized.
- Avoid extra content blocks that repeat the same message.

### 4. SEO and indexing

- Keep unique title tags and meta descriptions on every page.
- Use one canonical URL per page.
- Make sure published pages are indexable and template pages stay marked `noindex`.

### 5. Conversion improvement

- Add one clear CTA per page.
- Make the CTA match the goal of the page.
- Use action language like "Submit", "View", "Join", or "Request".

## Suggested Rewrite Rules

- Keep each paragraph focused on one idea.
- Use specific facts instead of generic praise.
- Avoid repeating the same sentence across multiple pages.
- Keep section headings descriptive and search-friendly.
- Put the strongest CTA near the top and once again near the bottom.

## Content To Gather Before Publishing

- Updated project descriptions
- Current photos or screenshots
- Dates and timelines
- Outcome metrics or results
- Links to demos, code, forms, or contact pages
- Contact person for each program

## Review Checklist

- Every page has a unique title tag.
- Every page has a unique meta description.
- Live pages do not use placeholder text.
- Internal links all work.
- Images load quickly and have useful alt text.
- The page has at least one clear CTA.
- The page answers what it is, who it is for, and what to do next.
